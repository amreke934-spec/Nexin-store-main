# متجر نيكسن - تطبيق الجوال (Nexin Store Flutter Mobile App)

تطبيق جوال متكامل وشغال 100% مبني بأحدث إصدارات **Flutter** ولغة **Dart**، يقدم تجربة مستخدم سريعة وعصرية لشحن الألعاب والبطاقات الرقمية وخدمات الكاش السريع في سوريا والوطن العربي، مع الحفاظ على الهوية البصرية الداكنة (Dark Gaming Theme) لمتجر نيكسن.

---

## 📱 محتويات وهيكلية المشروع (Project Architecture)

```
flutter_app/
├── pubspec.yaml                 # الاعتمادات والمكتبات
├── README.md                    # دليل التثبيت والتشغيل
└── lib/
    ├── main.dart                # نقطة الانطلاق الرئيسية مع دعم RTL واللغة العربية
    ├── constants/               # الثوابت والألوان والسمات
    │   ├── app_colors.dart      # ألوان هوية نيكسن (الأرجواني النيون والسيان السماوي)
    │   ├── app_theme.dart       # تهيئة سمة التطبيق وخط Cairo
    │   └── api_constants.dart   # نقاط النهاية وعناوين الـ API
    ├── models/                  # نماذج البيانات (Data Models)
    │   ├── user_model.dart      # نموذج المستخدم والمحفظة
    │   ├── product_model.dart   # نموذج الباقات ومجموعات الألعاب
    │   ├── order_model.dart     # نموذج الطلبات والتتبع
    │   ├── banner_model.dart    # نموذج البانرات الإعلانية
    │   └── deposit_model.dart   # نموذج طرق الإيداع وسجل الحوالات
    ├── services/                # خدمات الشبكة وجلب البيانات (APIs)
    │   ├── api_service.dart     # عميل HTTP موحد مع Bearer Token والتحكم بالأخطاء
    │   ├── auth_service.dart    # الدخول، التسجيل، والتحقق بكود OTP
    │   ├── store_service.dart   # جلب المنتجات، الباقات، وتصنيف الألعاب
    │   ├── order_service.dart   # إنشاء الطلبات وتتبعها ومزامنتها
    │   └── deposit_service.dart # جلب طرق الإيداع وتقديم إشعارات التحويل
    ├── providers/               # إدارة الحالة (State Management)
    │   ├── auth_provider.dart   # إدارة جلسة المستخدم والرصيد المباشر
    │   ├── store_provider.dart  # إدارة المنتجات، الفلترة، والبحث السريع
    │   └── order_provider.dart  # إدارة سجل الطلبات والتتبع اللحظي
    ├── widgets/                 # عناصر واجهة المستخدم القابلة لإعادة الاستخدام
    │   ├── nexin_logo.dart      # شعار نيكسن الأيقوني المتوهج
    │   ├── banner_slider.dart   # سلايدر البانرات مع مؤشر النقاط
    │   ├── game_card.dart       # كرت عرض اللعبة مع عدد الباقات
    │   ├── package_card.dart    # كرت اختيار الباقة وتحديدها
    │   ├── balance_card.dart    # كرت محفظة الرصيد مع زر الإيداع
    │   ├── order_item_card.dart # كرت عرض الطلب وحالته مع نسخ الرقم
    │   ├── custom_button.dart   # زر عصري متدرج مع حالة التحميل
    │   └── custom_text_field.dart # حقل إدخال يدعم اللصق وتحديد الأرقام
    └── screens/                 # شاشات التطبيق الكاملة
        ├── splash_screen.dart   # شاشة البداية المتحركة
        ├── main_navigation_screen.dart # شريط التنقل السفلي
        ├── home_screen.dart     # الصفحة الرئيسية للمتجر والبحث
        ├── game_packages_screen.dart # صفحة استعراض باقات اللعبة المحددة
        ├── checkout_screen.dart # صفحة الدفع والشحن المباشر وفحص الرصيد
        ├── orders_screen.dart   # سجل طلبات المستخدم والفلترة
        ├── order_tracking_screen.dart # شاشة تتبع حالة الطلب بالرقم
        ├── deposit_screen.dart  # صفحة إيداع الرصيد وحساب الصرف
        ├── profile_screen.dart  # الحساب الشخصي والآيديات المحفوظة
        └── auth_screen.dart     # تسجيل الدخول وتأكيد الرمز
```

## 🚀 كيفية تشغيل التطبيق (Getting Started)

### 1. المتطلبات الأساسية
- تثبيت Flutter SDK (الإصدار 3.0 فما فوق).
- Android Studio أو VS Code مع حزمة إضافات Flutter & Dart.

### 2. تثبيت الحزم والمكتبات
افتح موجه الأوامر داخل مجلد `flutter_app` ونفّذ:
```bash
cd flutter_app
flutter pub get
```

### 3. تشغيل التطبيق في وضع التطوير
للتشغيل على محاكي أندرويد أو جهاز حقيقي موصول بالـ USB:
```bash
flutter run
```

### 4. استخراج حزمة الأندرويد النهائية (Build Release APK)
```bash
flutter build apk --release
```
ستجد الملف الناتج في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

## ⚙️ ربط التطبيق بالسيرفر (API Configuration)

* يمكنك تغيير عنوان السيرفر من خلال ملف `lib/constants/api_constants.dart` بتعديل المتغير `defaultBaseUrl`.
* كما يتيح التطبيق للمستخدم والمشرف تعديل رابط الخادم مباشرة من داخل شاشة **حسابي والإعدادات > عنوان السيرفر** دون الحاجة لإعادة تجميع الكود!

## ✨ المميزات الرئيسية للتطبيق
1. **تصميم الألعاب النيون المتكامل**: درجات ألوان متناسقة، خلفيات فخمة، حواف منحنية، وتأثيرات زجاجية (Glassmorphism).
2. **شحن مباشر وفوري**: ملء تلقائي لمعرفات اللاعبين المحفوظة (Player ID) ودعم لصق الأرقام بضغطة زر.
3. **فحص لحظي للرصيد**: تنبيه مباشر للمستخدم عند عدم كفاية الرصيد مع توجيهه الفوري لصفحة الإيداع.
4. **حاسبة أسعار الإيداع**: حساب فوري للمبلغ بالليرة السورية ومراعاة سعر الصرف ونسبة الرسوم لكل طريقة دفع (سيريتل كاش، MTN كاش، USDT، إلخ).
5. **مزامنة الطلبات قيد المعالجة**: فحص وتحديث تلقائي لحالة الطلبات المعلقة واسترجاع الرصيد فوراً في حال رفض أو فشل المورد.
